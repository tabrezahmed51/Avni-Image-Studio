# Security Policy

## Supported Versions
We release patches for the following versions:
- `main` branch (active development)
- Latest stable release

## Reporting a Vulnerability
If you discover a vulnerability:
- Open a private security advisory in GitHub (Security → Advisories → New Draft).
- Or email: security@yourdomain.com

Please include:
- Steps to reproduce
- Impact assessment
- Suggested fix (if any)

## Responsible Disclosure
We ask that you:
- Do not publicly disclose before a fix is released.
- Allow reasonable time for remediation.
- Collaborate with maintainers for verification.

## Dependencies
We monitor vulnerabilities via Dependabot alerts.
Critical issues are patched within **72 hours**.
